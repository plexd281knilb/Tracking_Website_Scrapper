# Spirit Tracker & Scraper (Bourbon Alert System)

An automated web scraper and notification application designed to track rare bourbon releases (e.g. Jack Daniel's Coy Hill, Twice Barreled) on retail sites such as **Goody Goody** and **Total Wine**, monitor the **Breaking Bourbon Release Calendar**, and alert you via email (SMTP) when target items become available.

---

## 📋 Features

- 🔍 **Retailer Scraper**: Scrapes inventory and stock status from websites like Goody Goody and Total Wine.
- 🎯 **Smart Filtering**: Filters out standard production bottles (e.g., Old No. 7, Gentleman Jack, Honey, Fire) while highlighting special releases.
- 📅 **Breaking Bourbon Release Calendar**: Automatically parses and displays upcoming bourbon releases with 1-click tracking.
- 📧 **SMTP Email Alerts**: Receive immediate email alerts when items switch to "In Stock". Includes an intuitive SMTP configuration page.
- 🖥️ **Sleek Web Dashboard**: Modern dark-mode interface displaying real-time availability, price tracking, and manual scrape triggers.
- 🐳 **Unraid & Docker Ready**: Containerized application ready to be deployed on Unraid via Docker and synced with GitHub.
